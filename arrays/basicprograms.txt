1. Print Elements of an Array

Purpose: Learn array traversal

import java.util.*;

public class Main {
    public static void main(String[] args) {

        int arr[] = {10, 20, 30, 40, 50};

        for(int i = 0; i < arr.length; i++) {
            System.out.println(arr[i]);
        }
    }
}

What you learn:

arr.length

indexing (arr[i])

2. Take Array Input from User

Purpose: Very important for DSA problems

import java.util.*;

public class Main {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int arr[] = new int[5];

        for(int i = 0; i < arr.length; i++) {
            arr[i] = sc.nextInt();
        }

        for(int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " ");
        }
    }
}

What you learn:

storing input in arrays

3. Find Largest Element

Purpose: comparison logic

public class Main {
    public static void main(String[] args) {

        int arr[] = {4, 7, 1, 9, 2};

        int max = arr[0];

        for(int i = 1; i < arr.length; i++) {
            if(arr[i] > max) {
                max = arr[i];
            }
        }

        System.out.println("Largest: " + max);
    }
}

6. Reverse an Array

Very common DSA starter problem.

public class Main {
    public static void main(String[] args) {

        int arr[] = {1,2,3,4,5};

        for(int i = arr.length - 1; i >= 0; i--) {
            System.out.print(arr[i] + " ");
        }
    }
}
7. Search an Element (Linear Search)

This is your first real DSA algorithm.

public class Main {
    public static void main(String[] args) {

        int arr[] = {10,20,30,40,50};
        int key = 30;

        for(int i = 0; i < arr.length; i++) {
            if(arr[i] == key) {
                System.out.println("Element found at index: " + i);
                return;
            }
        }

        System.out.println("Element not found");
    }
}
8. Count Even and Odd Numbers
public class Main {
    public static void main(String[] args) {

        int arr[] = {1,2,3,4,5,6};

        int even = 0;
        int odd = 0;

        for(int i = 0; i < arr.length; i++) {
            if(arr[i] % 2 == 0) {
                even++;
            } else {
                odd++;
            }
        }

        System.out.println("Even: " + even);
        System.out.println("Odd: " + odd);
    }
}
